# History of JavaScript
In 1995 - Created by Brendan Eich at Netscape in just 10 days

## `Mocha` ---> `LiveScript` ---> `JavaScript`

Switching from LiveScript to JavaScript was a smart move to make it sound cooler and
piggyback on Java's fame, while also cozying up to Sun Microsystems

--------------------------------------------------------------------------
```JS
1996 ---> JAVASCRIPT ---> JavaScript was created

1997 ---> ECMA INTERNATIONAL ---> It was then submitted to ECMA International for standardization, which resulted in ECMAScript
```
